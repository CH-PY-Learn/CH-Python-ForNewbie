# 变量

## 概览

变量可以储存各种类型的数据。常见的类型有：

- 数字
- 布尔值
- 字符串
- 列表
- 字典
- 集合
- 函数

## 初始化变量

在定义变量或第一次为变量赋值时，我们称这个过程为初始化。

```python
# 一些代码
my_age = 18  # my_age 第一次被赋值，被初始化为 18
# 后续代码
```

在这段代码中，`my_age` 在最后一行被初始化。变量被赋值后，它所表示的值就等于等号右侧被赋予的值。

例如：

```python
my_age = 18
```

那么变量 `my_age` 的值就是 `18`。

## 变量命名

变量名可以由中文、英文、数字和下划线 `_` 组成，但不能在开头放数字。

```python
my_age = 18
学生年龄 = 18
代号1 = 987654321
```

实际编写 Python 代码时，通常使用英文和下划线为变量命名，例如 `my_age`。这种写法更符合常见的 Python 编程习惯，也便于与其他开发者协作。
