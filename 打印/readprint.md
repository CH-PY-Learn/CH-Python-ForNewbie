# `print()` 函数

## 概览

`print()` 可以将 Python 表达式的结果输出到终端。运行代码时，终端通常位于编辑器下方的窗口中。

Python 表达式是能够被 Python 解读的内容，例如：

- 字符串
- 数字
- 其他数据类型

## 打印文本

```python
print("文本")
```

要让程序知道需要打印的内容，应将文本放入 `print()` 的括号中，并用引号包裹。引号中的内容会被原样输出。

## 打印数字、变量或表达式

除了用引号包裹的文本，也可以打印不带引号的 Python 表达式：

```python
print(1 + 1)
```

Python 会先计算 `1 + 1`，再输出结果 `2`。

如果已经定义变量 `a`，且 `a` 的值为 `1`，同样可以打印该变量：

```python
a = 1
print(a)  # 输出：1
```

## 在一行中打印多个表达式

使用逗号可以在一行中打印多个表达式：

```python
print("Hello", "World!")  # 输出：Hello World!
```

`print()` 会忽略代码中逗号两侧的空格；默认情况下，逗号分隔的各项输出时会以一个空格间隔。

## `sep` 参数

`sep` 是 *separate* 的缩写，用于指定多个表达式之间的间隔内容。

```text
print(表达式1, 表达式2, sep=间隔内容)
```

`sep` 的值也必须是字符串或者数据类型 `None`。它是 `print()` 的内置参数，无需额外定义。例如：

```python
print("2026", "08", "20", sep="-")  # 输出：2026-08-20
```

## `end` 参数

`end` 也是 `print()` 的内置参数，用法与 `sep` 类似，用于指定每次打印结束后的内容。它默认是换行符 `\n`。

```python
print("Hello", end=" ")
print("World!")  # 输出：Hello World!
```

使用 `sep` 和 `end` 时，其他需要打印的表达式应放在这两个参数之前。

## f-string

f-string 可以在同一对引号中直接组合文本与 Python 表达式，无需使用逗号。

```python
name = "小明"
print(f"你好，{name}！")  # 输出：你好，小明！
```

使用 f-string 时，在字符串引号前加上 `f`。花括号 `{}` 中的内容会被 Python 解读，例如变量或其他表达式。
