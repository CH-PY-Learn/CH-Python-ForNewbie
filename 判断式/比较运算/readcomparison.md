# 判断式

## 概览

判断式可以让程序在执行条件判断后，决定是否执行缩进内的代码。判断式的结果只有 `True` 和 `False`：结果为 `True` 时执行缩进内容，结果为 `False` 时略过缩进内容。

```python
if True:
    print("判断式成立")

if False:
    print("这段缩进不会被执行")
```

## 比较运算符

在判断式中，一般使用比较运算符判断条件是否成立：

- `!=` 表示左右两边的表达式不相等。
- `==` 表示左右两边的表达式相等。
- `>=` 表示左边的表达式大于或等于右边的表达式。
- `<=` 表示左边的表达式小于或等于右边的表达式。
- `>` 表示左边的表达式大于右边的表达式。
- `<` 表示左边的表达式小于右边的表达式。

```python
if 1 + 1 == 2:
    print("1 + 1 等于 2，判断式成立")
```

上面的判断式会先计算 `1 + 1` 的值；如果结果等于 `2`，就执行缩进内的代码。

## 缩进

在 Python 中，缩进用于表示代码属于哪个代码块。`:` 表示一个代码块开始，下一行需要缩进。

任意数量的空格都可以代表一级缩进，但通常使用 4 个空格作为一级缩进：

```python
age = 18

if age >= 18:
    print("可以进入")
    print("欢迎！")

print("判断式结束")
```

两个缩进的 `print()` 都属于 `if` 代码块，只有条件成立时才会执行；最后一行没有缩进，不属于 `if` 代码块，因此一定会执行。

同一个代码块中的缩进必须保持一致。

## `if-else`

`if-else` 表示当判断式为 `False` 时，执行 `else` 代码块的内容；当判断式为 `True` 时，则不执行 `else` 代码块的内容：

```python
rarity = "Epic"

if rarity != "Epic":
    ...
else:
    print("Epic稀有度")
```

在以上代码中，判断式 `rarity != "Epic"` 不成立，因此会执行 `else` 代码块的内容。

## `if-elif-else`

当变量可以同时满足多个判断式，而程序员只需要一个判断式的代码块执行时，应使用 `if-elif`：

```python
score = 80

if score >= 80:
    print("优秀")

elif score >= 60:
    print("及格")

else:
    print("不及格")
```

在以上代码中，`score` 变量同时满足 `>= 80` 和 `>= 60` 的条件，但程序只会执行 `score >= 80` 的代码块。

在 `if-elif` 写法中，会从上至下依次判断第一个 `if` 或 `elif`。当第一个判断式成立时，就会执行该判断式的代码块，并跳过后续的 `elif` 和 `else`。

`else` 只在每个 `if` 和 `elif` 判断式都不成立时才执行。
