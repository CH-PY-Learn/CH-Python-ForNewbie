# 索引

## 概览

索引用于读取可储存多个数据的数据类型中的某个单独数据。能够储存多个数据的常见类型包括集合、列表、字符串、字典和元组。

为了便于读取数据中某个单独数据的内容，索引值与数据中存放该数据的顺序一一对应。集合具有无序性，因此不能使用索引读取。

为了表示索引值，应该在指向数据的变量后使用中括号 `[]`，并在括号内放入整数值表示索引。

## 正向索引

正向索引从左到右计算：

```text
数据索引值 = 数据从左到右顺序中的第（索引值 + 1）个数据
```

```python
date_tuple = (22, 1, 2010)
print(date_tuple[1])  # 输出：1
```

`date_tuple[1]` 表示 `date_tuple` 中第 `1 + 1` 个数据，`1` 是索引值。

## 负向索引

索引允许使用负数。负数索引从右到左计算：

```text
负数索引值 = 数据从左到右顺序中倒数第（索引值的绝对值）个数据
```

```python
date_tuple = (22, 1, 2010)
print(date_tuple[-1])  # 输出：2010
```

`date_tuple[-1]` 表示倒数第一个数据。

## `0` 与 `-0`

`0` 不是正数也不是负数，因此使用 `-0` 作为索引值时，效果与 `0` 相同：

```python
date_tuple = (22, 1, 2010)
print(date_tuple[-0])  # 输出：22
print(date_tuple[0])   # 输出：22
```

在索引值为 `0` 时，无论是否写负号，都遵守正向索引的规则：读取数据从左到右顺序中的第 `索引值 + 1` 个数据。
