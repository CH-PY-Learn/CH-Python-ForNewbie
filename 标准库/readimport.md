# 标准库与模块导入（`import`）

## 概览

Python 标准库是随 Python 解释器一同安装的内置模块集合。标准库包含了处理时间、数学计算、字符串处理、文件操作、网络通信等众多常用工具。

使用标准库模块无需通过 `pip*` 命令额外下载安装，在代码中通过 `import` 语句引入即可使用。

---

## 模块导入的常见写法

在 Python 中，导入模块主要有 `import 模块名`、`from 模块名 import 对象` 以及通配符导入 `from 模块名 import *` 等语法形式。

### 1. `import a`（导入整个模块）

- **语法格式**：
  ```python
  import 模块名
  ```
- **调用方式**：
  必须通过 `模块名.函数名()` 或 `模块名.变量名` 的形式进行访问。
- **特点与行为**：
  - 导入整个模块命名空间。
  - 调用时带有模块名前缀，能够明确区分同名函数来自哪个模块，避免命名冲突。

```python
import math

# 使用 math. 前缀调用库中的函数和常量
root_value = math.sqrt(16)
pi_value = math.pi

print("平方根：", root_value)
print("圆周率：", pi_value)
```

---

### 2. `from a import b`（从模块中导入指定对象）

- **语法格式**：
  ```python
  from 模块名 import 函数名, 类名, 常量名
  ```
- **调用方式**：
  直接使用导入的名称，不需要添加模块名前缀。
- **特点与行为**：
  - 仅将指定的函数、类或常量导入到当前代码的命名空间中。
  - 调用时无需重复书写模块名前缀，代码更为紧凑。

```python
from math import sqrt, pi

# 直接使用导入的函数和常量，无需写 math.
root_value = sqrt(16)
pi_value = pi

print("平方根：", root_value)
print("圆周率：", pi_value)
```

也可以一次性导入多个对象，各个对象之间用英文逗号 `,` 分隔：

```python
from time import time, sleep
```

---

### 3. `from a import *`（通配符导入所有对象）

- **语法与调用**：使用 `from 模块名 import *` 会将模块内所有公开对象（未以 `_` 开头的名称）直接导入当前命名空间，调用时可直接使用函数名或变量名。
- **利与弊**：
  - **利**：书写省力，无需逐个列出导入名称，调用时也无需添加模块名前缀。
  - **弊**：容易造成命名空间污染；当多个模块存在同名对象时会发生覆盖，且难以直观追溯某个具体对象的来源。

---

## 导入方式的对比

| 导入写法                  | 调用形式        | 特点与适用情况                                                         |
|:--------------------------|:----------------|:-----------------------------------------------------------------------|
| `import 模块名`           | `模块名.对象`   | 命名空间独立清晰，适合需要调用模块内大量不同功能或防止函数名冲突的场景 |
| `from 模块名 import 对象` | 直接使用 `对象` | 书写简短直观，适合只频繁使用模块中少数特定函数或常量的场景             |
| `from 模块名 import *`    | 直接使用 `对象` | 省去前缀与逐一声明，但存在命名空间污染与同名覆盖风险，不易溯源对象出处 |
