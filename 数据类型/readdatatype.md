# 数据类型

## 概览

Python 中常见的数据类型包括：

- `str（String）`：字符串
- `int`：整数
- `None`：无值
- `bool`：布尔值
- `float`：浮点数
- `list`：列表
- `tuple`：元组
- `set`：集合
- `dict`：字典
- `function`：函数

## `str（String）`：字符串

字符串需要用引号包裹。单引号、双引号和三引号都可以表示字符串：

```python
'文本内容'
"文本内容"
"""文本内容"""
```

三引号字符串可以直接包含换行；单引号和双引号字符串通常使用换行符 `\n` 表示换行。三引号中同样也可以使用 `\n`。

## `int`：整数

Python 中的整数可以储存无限大的数字，实际主要受电脑内存限制。

## `None`：无值

`None` 表示没有值。

## `bool`：布尔值

布尔值分为 `True` 和 `False`。

空列表、空字符串、空字典、`None`、`False`、数字 `0` 和浮点数 `0.0`（只要在数学上为 0），在布尔判断中都会被视为 `False`。通俗来说，它们表示空的数据或零值。

除这些假值外，其他符合 Python 表达式的值通常会被视为 `True`。

布尔值实际上是一种特殊的整数，`True` 对应 `1`，`False` 对应 `0`。

## `float`：浮点数

浮点数用于表示小数：

```python
number = 3.14
```

整数相除时，结果默认是浮点数：

```python
print(3 / 2)  # 输出：1.5
```

## `list`：列表

列表可以使用 `[内容]` 或 `list(内容)` 表示：

```python
numbers = [1, 2, 3]
```

当需要在列表中查询一个目标时，通常会从头到尾遍历列表，直到找到第一个与目标值相等的元素。

遍历是指沿着某条搜索路线，依次对一个数据结构中的每个元素进行一次访问。

## `tuple`：元组

元组可以使用 `(数据, 数据)` 或 `数据, 数据` 表示：

```python
numbers = (1, 2, 3)
other_numbers = 1, 2, 3
```

不使用括号时，逗号会使多个数据默认组成元组。只要包含逗号且没有被其他括号（如 `[]`）包裹的都表示元组。

如果使用多元赋值，如 `a, b = c, d`，代表把右边的值逐个解包赋值给左边。

## `set`：集合

集合可以使用 `{内容}` 或 `set()` 表示：

```python
numbers = {1, 2, 3}
```

集合通过哈希表实现，一般用于判断目标值是否在数据中。哈希是通过特定算法将任意长度的输入转化为固定长度输出的过程，因此可以快速判断一个值是否在集合内。

集合不会保留重复的数据：

```python
print({1, 1})  # 输出：{1}
```

## `dict`：字典

字典可以使用 `{}` 或 `dict()` 表示，通过哈希表实现。字典由键值对组成：

```python
student = {
    "name": "小明",
    "age": 12,
}  # 也可以压缩在一行里表示，只是分行储存多个数据更直观
```

键具有唯一性，不能创建两个相同的键；如果再次为同一个键赋值，新值会替换原来的值。

字典的值只要是 Python 表达式即可，键必须是可哈希的值（一般不可变的数据都是可哈希的）。

不可变的数据类型包括：`str`、`tuple`、`int`、`float`、`bool`。

## `function`：函数

函数是比较特殊的 Python 表达式，一般是自己定义的函数或内置函数。

函数名后加上括号表示调用，例如 `print()`；不加括号的 `print` 是一个表达式，代表函数自身。
