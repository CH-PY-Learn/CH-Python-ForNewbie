# `input()` 输入函数

## 概览

在 Python 中，`input()` 函数用于实现程序与用户的交互。

当程序运行到 `input()` 时会暂停执行，等待用户在控制台中通过键盘输入内容，并在用户按下回车键（Enter）后继续运行。

```python
user_name = input("请输入您的名字：")
print("你好，" + user_name)
```

## 基本用法

`input()` 的括号内可以填入一段提示文本（字符串），用于引导用户输入相应的信息。

用户输入的内容会被 `input()` 函数作为**字符串（`str`）类型**返回：

```python
hobby = input("请输入你的爱好：")

print("你的爱好是：" + hobby)
print("输入内容的类型是：", type(hobby))
```

无论用户输入的是字母、汉字还是纯数字，`input()` 接收到的结果始终是字符串类型。

## 输入内容类型转换

由于 `input()` 返回的数据固定为字符串类型，如果需要将输入内容用于数学计算或比较运算，必须使用类型转换函数（如 `int()` 或 `float()`）将其转换为数值类型：

```python
age_text = input("请输入您的年龄：")
age = int(age_text)

if age >= 18:
    print("您已成年")
else:
    print("您未成年")
```

也可以将 `input()` 直接嵌套在转换函数内部：

```python
score = float(input("请输入您的考试成绩："))
```

## 注意事项

- **回车确认**：用户在终端输入完毕后，必须按下回车键，程序才会接收输入并继续向下执行。
- **类型报错（`ValueError`）**：如果尝试将非纯数字字符串（如 `"abc"`）转换为 `int()` 或 `float()`，程序会因抛出 `ValueError` 异常而中断崩溃。为了防止程序报错崩溃，可以使用 `try-except` 语句进行防报错处理。
