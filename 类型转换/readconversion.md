# 类型转换

## 概览

在 Python 中，将一种数据类型转换为另一种数据类型的过程称为类型转换（Type Conversion）。

类型转换通常分为两类：
- **隐式类型转换（自动转换）**：由 Python 解释器在运算过程中自动完成，无需人工干预。
- **显式类型转换（强制转换）**：通过调用 Python 内置的转换函数，显式地将数据转换为目标类型。

## 隐式类型转换

当不同数值类型的数据混合运算时，Python 会自动将取值范围较小或精度较低的数据类型转换为精度更高的数据类型，以防止精度丢失：

- **整数与浮点数运算**：整数会自动转换为浮点数后再进行计算。
- **除法运算 `/`**：无论被除数与除数是整数还是浮点数，计算结果默认均为浮点数。

```python
num_int = 10
num_float = 2.5

result = num_int + num_float  # 自动转换为浮点数：12.5
```

## 显式类型转换

显式类型转换通过 Python 内置函数实现，常用的转换函数包括：

- `int()`：将数据转换为整数。
- `float()`：将数据转换为浮点数。
- `str()`：将数据转换为字符串。
- `bool()`：将数据转换为布尔值。
- `list()`：将可迭代对象转换为列表。
- `tuple()`：将可迭代对象转换为元组。
- `set()`：将可迭代对象转换为集合。
- `dict()`：将包含键值对结构的数据转换为字典。

## 常用转换函数详解

### 1. `int()`：转换为整数

- **浮点数转整数**：直接截断并舍去小数部分（不进行四舍五入）。
  ```python
  int(3.14)   # 结果为 3
  int(9.99)   # 结果为 9
  ```
- **字符串转整数**：字符串内容必须是纯整数格式（可包含正负号和首尾空白字符），包含小数点的字符串无法直接通过 `int()` 转换。
  ```python
  int("100")   # 结果为 100
  int("-50")   # 结果为 -50
  # int("3.14")  # 报错 ValueError：无法直接将浮点数字符串转为整数
  ```
- **布尔值转整数**：
  ```python
  int(True)    # 结果为 1
  int(False)   # 结果为 0
  ```

### 2. `float()`：转换为浮点数

- **整数转浮点数**：在整数末尾添加 `.0`。
  ```python
  float(10)    # 结果为 10.0
  ```
- **字符串转浮点数**：字符串内容只要是合法的数字表示（整数字符串或浮点数字符串均可）即可成功转换。
  ```python
  float("3.14")  # 结果为 3.14
  float("100")   # 结果为 100.0
  ```
- **布尔值转浮点数**：
  ```python
  float(True)    # 结果为 1.0
  float(False)   # 结果为 0.0
  ```

### 3. `str()`：转换为字符串

`str()` 可以将几乎所有 Python 表达式和数据类型转换为字符串形式，常用于格式化输出或文本拼接：

```python
str(100)        # 结果为 "100"
str(3.14)       # 结果为 "3.14"
str(True)       # 结果为 "True"
str([1, 2, 3])  # 结果为 "[1, 2, 3]"
```

### 4. `bool()`：转换为布尔值

`bool()` 用于判断一个值在布尔上下文中为真（`True`）还是为假（`False`）。

- **转换为 `False` 的假值（零值或空数据）**：
  - 数字零：`0`、`0.0`
  - 空容器与空序列：`""`（空字符串）、`[]`（空列表）、`()`（空元组）、`{}`（空字典）、`set()`（空集合）
  - 特殊值：`None`、`False`
- **转换为 `True` 的真值**：
  - 除上述假值以外的所有非零数值、非空字符串及非空容器等均转换为 `True`。

### 5. 容器类型之间的转换

- **`list()` / `tuple()` / `set()` 互转**：
  - 字符串转换为列表或元组时，会按字符逐个拆分。
  - 列表转换为集合时，会自动去除重复元素（但会丢失原有顺序）。
  ```python
  text = "hello"
  list(text)   # 结果为 ['h', 'e', 'l', 'l', 'o']
  
  numbers = [1, 2, 2, 3, 3, 4]
  set(numbers)  # 结果为 {1, 2, 3, 4}（去重）
  ```
- **`dict()` 转换**：
  - 需要传入包含二元键值对结构的可迭代对象（如二元元组构成的列表）。
  ```python
  pairs = [("name", "小明"), ("age", 18)]
  dict(pairs)  # 结果为 {'name': '小明', 'age': 18}
  ```

## 常见错误与注意事项

- **`ValueError`**：尝试转换格式不符合要求的字符串时会抛出异常，如 `int("abc")` 或 `int("3.14")`。若需要将浮点数字符串转为整数，可先转为浮点数再转整数：`int(float("3.14"))`。
- **`TypeError`**：尝试对不可迭代的对象使用容器转换函数时会抛出异常，如 `list(100)`。
- **精度丢失**：浮点数转换为整数时会直接截断小数部分，若需四舍五入可结合 `round()` 函数使用。
