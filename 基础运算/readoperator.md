# 运算符

## 概览

基础运算符包括加减法、乘除法、次方和取余。

## 运算优先级

Python 中的数学表达式也有运算优先级。例如，次方的优先级高于乘除法，乘除法的优先级高于加减法。

优先级表示表达式计算的先后顺序，括号内的表达式优先级最高：

```python
(1 + 2) * 3  # 会优先计算 1 + 2 的值
```

## 基础运算符

对于任意两个数学表达式，可以使用以下运算符：

- 加法使用 `+`
- 减法使用 `-`
- 乘法使用 `*`
- 除法使用 `/`
- 次方使用 `**`
- 取余使用 `%`

基础的四则运算不在这里过多赘述，请查看本文件夹中对应的示例文件。

## 次方

次方使用 `**` 表示：

```python
x ** y
```

当 `x` 和 `y` 都是数字时，表达式 `x ** y` 返回 `x` 的 `y` 次方。

## 取余

取余使用 `%` 表示：

```python
a % b
```

当 `a` 和 `b` 都是数字时，表达式 `a % b` 返回 `a` 除以 `b` 的余数。
