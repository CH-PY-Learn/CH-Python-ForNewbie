# 字符串格式化输出

## 概览

在 Python 中，输出格式控制用于对数字、文本等内容的显示样式进行精确设置。通过在 f-string 或 `format()` 方法的花括号内使用英文冒号 `:`，并在冒号后添加**格式说明符（Format Specifiers）**，可以控制小数位数、显示类型、对齐宽度、千位分隔符以及进制转换等。

### 基本语法结构

```text
{表达式:格式说明符}
```

例如：`{pi_value:.2f}` 表示将变量 `pi_value` 以保留两位小数的浮点数形式输出。

---

## 1. 浮点数与精度控制

### 定点小数格式（`f` 与 `F`）

- **`:.nf`**：指定保留 `n` 位小数（按四舍五入规则处理）。
- **示例**：
  ```python
  pi = 3.14159265
  print(f"{pi:.2f}")  # 输出: 3.14
  print(f"{pi:.4f}")  # 输出: 3.1416
  print(f"{pi:.0f}")  # 输出: 3（保留 0 位小数）
  ```

---

### 通用数字格式（`g` 与 `G`）

- **`:g` / `:G`**：通用格式（General format）。根据数值的大小自动在**定点表示法（`f`）**与**科学计数法（`e`）**之间进行选择，并且会**自动省略末尾多余的 0**。
- **行为特征**：
  - 当数值在正常显示范围内时，输出为定点数，但去除多余的尾随 0（如 `12.300` 显示为 `12.3`，`5.0` 显示为 `5`）。
  - 当数值非常大或非常小时（指数小于 `-4` 或大于等于指定精度），自动切换为科学计数法。
- **示例**：
  ```python
  number1 = 12.3000
  number2 = 0.0000456
  number3 = 123456789.0

  print(f"{number1:g}")  # 输出: 12.3（自动去除多余的 0）
  print(f"{number2:g}")  # 输出: 4.56e-05（自动使用科学计数法）
  print(f"{number3:g}")  # 输出: 1.23457e+08
  ```

---

### 科学计数法格式（`e` 与 `E`）

- **`:.ne` / `:.nE`**：以指数形式（科学计数法）输出，`n` 指定小数位数。
- **示例**：
  ```python
  distance = 150000000.0
  print(f"{distance:.2e}")  # 输出: 1.50e+08
  print(f"{distance:.2E}")  # 输出: 1.50E+08
  ```

---

## 2. 百分比格式（`%`）

- **`:.n%`**：自动将数值乘以 `100`，以定点小数输出并在末尾添加百分号 `%`。
- **示例**：
  ```python
  rate = 0.856
  print(f"{rate:.1%}")  # 输出: 85.6%
  print(f"{rate:.2%}")  # 输出: 85.60%
  ```

---

## 3. 千位分隔符（`,` 与 `_`）

- **`:,`**：使用英文逗号作为千位分隔符。
- **`:_`**：使用下划线作为千位分隔符。
- 可以与小数精度组合使用（如 `:,.2f`）。
- **示例**：
  ```python
  money = 1234567890.5
  print(f"{money:,}")      # 输出: 1,234,567,890.5
  print(f"{money:_}")      # 输出: 1_234_567_890.5
  print(f"{money:,.2f}")   # 输出: 1,234,567,890.50
  ```

---

## 4. 整数进制转换

- **`:d`**：十进制整数（默认）。
- **`:b`**：二进制（Binary）。
- **`:o`**：八进制（Octal）。
- **`:x` / `:X`**：十六进制（Hexadecimal，小写/大写）。
- 搭配 `#` 前缀可在输出中保留 `0b`、`0o`、`0x` 前缀标识。
- **示例**：
  ```python
  num = 42
  print(f"二进制: {num:b}, 带前缀: {num:#b}")    # 输出: 二进制: 101010, 带前缀: 0b101010
  print(f"八进制: {num:o}, 带前缀: {num:#o}")    # 输出: 八进制: 52, 带前缀: 0o52
  print(f"十六进制: {num:x}, 带前缀: {num:#X}")  # 输出: 十六进制: 2a, 带前缀: 0X2A
  ```

---

## 5. 对齐与填充宽度

- **`:<宽度`**：左对齐。
- **`:>宽度`**：右对齐（数字默认右对齐）。
- **`:^宽度`**：居中对齐。
- **`:[填充字符][对齐方式][宽度]`**：在空白处填充指定字符。
- **`:n>宽度`** 或 **`:n宽度`**：n为整数（一般放0），专门用于数字前补零（常用于编号对齐）。
- **示例**：
  ```python
  text = "Python"
  print(f"{text:<10}")       # 输出: "Python    "（左对齐，占 10 字符）
  print(f"{text:>10}")       # 输出: "    Python"（右对齐，占 10 字符）
  print(f"{text:^10}")       # 输出: "  Python  "（居中对齐）
  print(f"{text:*^12}")      # 输出: "***Python***"（用 * 填充居中）

  item_id = 7
  print(f"{item_id:0>5}")    # 输出: "00007"（5 位宽度，前面补 0）
  ```

---

## 6. 正负符号控制

- **`:+`**：正数显示 `+`，负数显示 `-`。
- **`:-`**：仅负数显示 `-`（默认行为）。
- **`: `（空格）**：正数前面保留一个空格，负数前面显示 `-`（便于多行正负数对齐）。
- **示例**：
  ```python
  pos_num = 15
  neg_num = -15

  print(f"{pos_num:+}, {neg_num:+}")  # 输出: +15, -15
  print(f"{pos_num: }, {neg_num: }")  # 输出:  15, -15
  ```

---

## 7. 格式说明符速查表

| 格式控制符 | 功能说明 | 示例代码 | 示例输出 |
| :--- | :--- | :--- | :--- |
| `:.2f` | 保留 2 位小数的浮点数 | `f"{3.14159:.2f}"` | `3.14` |
| `:g` | 通用格式（自动选科学/定点并去尾零） | `f"{12.300:g}"` | `12.3` |
| `:.2e` | 科学计数法（保留 2 位小数） | `f"{1500:.2e}"` | `1.50e+03` |
| `:.1%` | 百分比格式（保留 1 位小数） | `f"{0.856:.1%}"` | `85.6%` |
| `:,` | 千位分隔符 | `f"{1000000:,}"` | `1,000,000` |
| `:b` / `:#b` | 二进制 / 带 `0b` 前缀 | `f"{10:#b}"` | `0b1010` |
| `:x` / `:#x` | 十六进制 / 带 `0x` 前缀 | `f"{255:#x}"` | `0xff` |
| `:>10` | 宽度为 10，右对齐 | `f"{'abc':>10}"` | `       abc` |
| `:0>5` | 宽度为 5，左侧补零 | `f"{42:0>5}"` | `00042` |
| `:+` | 强制显示正负符号 | `f"{10:+}"` | `+10` |
